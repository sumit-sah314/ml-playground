---
name: Teaching constraints
description: User's product constraints for ML Playground lessons
---

ML Playground should teach machine-learning concepts visually, step by step, in beginner-friendly language. Use plain JavaScript and HTML canvas or Plotly, implementing all math from scratch without ML libraries.

**Why:** The user explicitly requested these constraints for the teaching app.

**How to apply:** Preserve the from-scratch math approach when extending lessons. Each lesson should include a short plain-English explanation, its key equation, an interactive visual, and a “Try this” challenge.
